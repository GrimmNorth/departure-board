# Fonts bundled with the firmware

Both are licensed under the SIL Open Font License 1.1 (see the OFL files here).

- `LondonUnderground-Regular.ttf` - London Underground Regular from the London TfL Dot Matrix Typeface by Sean Petykowski, unmodified.
  https://github.com/petykowski/London-Underground-Dot-Matrix-Typeface
- `BitcountPropDouble-Dots.ttf` - a static instance of Bitcount Prop Double (weight 500, round dots: ELSH 100) by the Bitcount Project Authors / Petr van Blokland.
  https://github.com/petrvanblokland/TYPETR-Bitcount

DotGothic16 and Handjet are downloaded from Google Fonts when the firmware is built.
